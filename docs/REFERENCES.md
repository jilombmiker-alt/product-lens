# 参考与来源边界

本仓库整理了用户场景取证、逆向机制分析、适配设计和分阶段工程验收的方法。方法规则、原产品观察和我们建议的实现分别记录。

- Skill目录采用`SKILL.md`及支持资料的组织形式，可参阅[Agent Skills](https://agentskills.io/)和[OpenAI Skills](https://github.com/openai/skills)。
- README的项目定位、工作流、快速开始与边界说明结构参考[Anthropic Skills](https://github.com/anthropics/skills)和[Superpowers](https://github.com/obra/superpowers)。没有内置其运行框架，也不声明获得其官方背书。
- 工程规则提炼自整理过程中使用的通用技术栈、前端及上线手册；未发布这些原始手册。默认技术是适配参考，实际实施需核对当前环境和官方依据。
- `references/blueprint.md`中的s01–s17是能力对照索引，不是行业统一标准，也不是已接通的生产工具。使用其他蓝图时应按能力建立映射。
- 本仓库不包含外部框架源码、真实客户对话、产品截图、账号资料或历史项目产物。用户另行提供的材料保持其原有权属。
